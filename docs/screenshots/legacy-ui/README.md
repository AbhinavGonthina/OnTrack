# Legacy UI

Kept for comparison only. Nothing here reflects how the app currently looks or works.

Notable differences from the current UI:

- A blue Sankey palette, replaced by the violet ordinal ramp used now
- The placeholder "OT" gradient badge, replaced by the current logo mark
- No resume upload, strength scoring, application search or pipeline stage counts
